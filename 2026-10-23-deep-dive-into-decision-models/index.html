Deep Dive into Decision Models

In this post I want to dig into exactly how decision models work. To do this I’m going to look into how Perplexity Decider v1.2 works at both an architecture and inference level and figure out what we can know about how it was trained based on that. I think this is a really useful model to look at because it’s on the frontier for decision models.

To start with let’s look at what a decision model is. A decision model, like Jev, which was really popular recently, is a model that can take in some input and some set of questions with possible categories and output one of those categories. So for instance, you could ask, “Is summary A a good summary for document A? True or false?”

The Recipe

The recipe is three parts.

  1. The model architecture
  2. Training
  3. Post-processing

Architecture

What makes Perplexity Decision Review 1.2 tick is starting with a strong foundation model, in this case Qwen 3.8 27B. We then modify the architecture by changing the attention to be non-causal for the full attention layers. As a reminder the Qwen architecture consists of a full attention layer stacked with linear attention via the gated delta network. We keep the linear attention to be causal but we change the full attention to be non-causal, meaning that each token can see future tokens.

We then kill the language modeling head from the model altogether. We’re not doing any kind of language modeling out so this saves us a lot of flops in our forward pass. Lastly we insert a new special token. In this case the token is <|fim_token]|> .

Anywhere we see <|fim_token]|> We decode with a small linear head that has 255 options so that linear head is an H-by-255 matrix multiply, where h is our model’s internal dimension.

When we’re decoding at inference time, we run this. We get a single 255-dimensional vector. We run softmax on that vector and we then get a probability distribution over all the possible choices.

Now if we have fewer than 255 choices, we will only decode that number of choices. If we only have A and B, we’d only decode two choices. Softmax normalizes this and gives us a probability distribution, which is what we return as the confidence.
